Quick Reference

Dimensionless Numbers

Re = ρvD/μReynolds number
Nu = hL/kNusselt number
Pr = μCp/kPrandtl number
Sh = k_c·L/D_ABSherwood number
Sc = μ/ρD_ABSchmidt number
Bi = hL/k_sBiot number

Heat Transfer

q = k·A·ΔT/LFourier conduction
q = h·A·ΔTNewton's cooling
Q = ṁ·Cp·ΔTSensible heat
Q = ṁ·ΔH_vapLatent heat
q = U·A·LMTDHeat exchanger duty
ε = q/q_maxNTU-ε method

Fluid Mechanics

ΔP = f·L/D·ρv²/2Darcy-Weisbach
Q = πR⁴ΔP/8μLHagen-Poiseuille
f = 64/ReLaminar friction factor
P/ρ+v²/2+gz = constBernoulli
ṁ = ρ·v·AContinuity (mass flow)

Thermodynamics

PV = nRTIdeal gas law
η = 1 − T_C/T_HCarnot efficiency
dU = δQ − δWFirst law (closed)
ΔG = ΔH − TΔSGibbs free energy
ln(P₂/P₁) = −ΔHvap/R·Δ(1/T)Clausius-Clapeyron

Key Constants

R = 8.314J/mol·K (ideal gas)
g = 9.81m/s² (gravity)
σ = 5.67×10⁻⁸W/m²·K⁴ (Stefan-Boltzmann)
k_B = 1.38×10⁻²³J/K (Boltzmann)
N_A = 6.022×10²³mol⁻¹ (Avogadro)
